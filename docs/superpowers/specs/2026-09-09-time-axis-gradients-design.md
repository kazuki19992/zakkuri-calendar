# 2日ビューの時間軸と曖昧さグラデーション設計

## 1. 目的

Issue #17では、2日ビューを予定一覧から24時間のタイムラインへ変更し、正確な予定とざっくりした時間表現を同じ時間軸上で比較できるようにする。時間表現の開始・終了・フェード比率は既存のSQLite定義を正とし、表示コードへ個別の時間帯を埋め込まない。

## 2. 決定事項

- 2日で共有する縦方向の24時間軸を表示し、その右に2日分のレーンを同じ幅で並べる。
- 内部の基準値は1時間56pt、15分14ptとするが、実際の表示は2日ビューのタイムライン領域(ヘッダーなどを除いた画面の残り高さ)に合わせて縮尺し、既定表示で24時間を画面内へ収める。縮尺前の基準値は最小表示高(36pt)など他の計算の基準としてのみ使う。
- 終日予定は時間軸より上の日別領域に表示する。
- 正確な予定は開始時刻と長さから位置・高さを決める。瞬間は時刻を示す線と最小36ptのラベル領域を持つ。
- 長さが「未定」の予定は設定Repositoryの分数を範囲として使い、開始を濃さのピーク、範囲の終端を透明とする。
- ざっくり予定は`TemporalDefinition.resolverConfig`、`fadeInRatio`、`fadeOutRatio`を使う。日粒度の`timeOfDay`だけを時間軸へ配置する。
- 日付をまたぐ予定は表示日ごとの区間へ分割する。グラデーションは分割区間ごとに作り直さず、元の全区間に対する濃さを切り出す。
- 同日に時間範囲が重なる予定は、貪欲法で重複レーンを割り当て、横幅を分割する。順序は開始、終了、IDで決定して再現可能にする。
- 色だけに依存せず、予定タイトル、時間表現、形状(角丸カード・グラデーション)、読み上げラベルを常に提供する。予定ブロック自体は枠線を持たないが、時間軸の罫線・列の区切り線は境界線のまま維持する。
- 予定タイトル・時間表現は、opacity stopのうち最も濃い区間の中心へ寄せて配置する(flex-start/center/flex-endの3段階)。フェードで両端が薄くなる予定でも、文字を濃い背景の上に置いて可読性を確保する。
- 表示中の2日のいずれかが今日を含む場合だけ、現在時刻線(赤色のtheme token `calendarNowIndicator`)を該当日の列へ引き、時間軸にも同じ色で現在時刻ラベルを表示する。1分ごとに再計算し、どちらの日も今日でなければ表示しない。
- 画面のノッチ・ホームインジケーターなどセーフエリアは`CalendarScreen`のルートで一括して確保する。2日ビューのタイムライン高さは、セーフエリアを差し引いた残り高さを基準に計算する。
- 月ビューの予定一覧と月セル件数は従来どおり`anchorDate`を基準にし、このPRでは変更しない。

## 3. レイヤー構成

### 3.1 Domain

`src/domain/temporal/resolve-event-time.ts`に、予定と時間表現定義から基準日内の分数範囲を解決する純粋関数を置く。

```text
resolveEventTime(event, definition, undeterminedFadeMinutes)
  -> allDay
  -> timed { startMinute, endMinute, fadeInRatio, fadeOutRatio, isInstant }
  -> unresolved
```

正確な予定は`HH:mm`を分へ変換する。固定時間はその分数、瞬間は開始と終了を同じ値、未定は設定値を終了へ加える。ざっくり予定は一致する日粒度`timeOfDay`定義だけを解決する。定義不在や異なる粒度は`unresolved`として、誤った時間へ置かない。

### 3.2 Feature presentation

`src/features/calendar/timeline-layout.ts`に次の純粋処理を置く。

- 表示日と予定の基準日の差から、0〜1440分へ区間をクリップする。
- 全区間上のフェード開始・終了位置を、表示区間内の0〜1のopacity stopへ変換する。
- 同日の区間へ重複レーンを割り当てる。
- 分数を時刻表示とアクセシビリティ文言へ変換する。

`TwoDayViewModel`は日ごとに`allDayItems`と`timelineItems`を持つ。`timelineItems`はUIがそのまま描画できる位置、最小表示高、重複レーン、opacity stopを含む。UIはRepositoryや時間解決規則を参照しない。

### 3.3 Hook

`useCalendarView`は予定、使用中の時間表現定義、未定時間の分数を並行取得し、表示モデルへ渡す。2日表示では、表示2日の前後に横スワイプ用の予備列(`TWO_DAY_SWIPE_BUFFER_DAYS`日、`docs/superpowers/specs/2026-09-09-two-day-calendar-ui-design.md`参照)を含めた範囲で予定を取得し、さらに先頭側はその1日前まで含めて日跨ぎ予定の継続描画に対応する。`twoDayStrip`が予備列を含む表示用モデルの並びを提供する。月表示の取得範囲は変更しない。

### 3.4 UI

`TwoDayView`は日付ヘッダーと終日領域を2列で表示した後、共通時間軸と2つの日別レーンを表示する。各レーンは時間線を持ち、`TimelineEventBlock`が絶対位置で予定を描画する。グラデーションはExpo SDK 57の`expo-linear-gradient`を使い、縦方向へ適用する。

## 4. フェード規則

全区間の長さを`D`、開始からピークへ達する比率を`fadeInRatio`、終了へ向けて薄くなる比率を`fadeOutRatio`とする。

- `0 / 0`: 全区間が最大濃度で、始点・終点とも明確。
- `>0 / 0`: 始点は透明で、`D * fadeInRatio`後に最大濃度となり、終点まで維持。
- `0 / >0`: 始点から最大濃度で、`D * (1 - fadeOutRatio)`後に薄くなり、終点で透明。
- `>0 / >0`: 始点と終点が透明で、その間に最大濃度区間または一点のピークを持つ。

未定時間は`0 / 1`とし、開始点が最大濃度になる。日跨ぎでクリップする場合は、クリップ境界での濃さと区間内の変曲点をstopへ含める。

## 5. 表示とアクセシビリティ

- 時間ラベルは3時間ごとに0:00から24:00まで(0, 3, 6, ..., 24)表示し、各時間の罫線は1時間ごとに同じ太さで表示する。24:00のラベルは軸の下端と同じ位置になるため、行の高さ分だけ上へずらしてはみ出さないようにする。
- 1時間の高さ(縮小後)は実機ピクセルへ丸めてから罫線位置を計算し、24本の罫線の間隔がすべて均一になるようにする。丸めずに実数のまま罫線ごとに独立して丸めると、間隔が1pxずつ不揃いに見える。
- 予定ブロックにはタイトルと「14:30・30分」「午後」「14:30・未定」などの時間表現を表示する。
- 予定ブロックの読み上げは、タイトル、時間表現、継続区間であることを含める。
- 文字が収まらない場合もアクセシビリティラベルには全文を保持する。
- ライト・ダークともtheme tokenから予定面、境界、文字色を決める。
- 現在時刻線・ラベルには読み上げ用のラベル(「現在時刻」「現在時刻14:32」)を付け、色だけに依存しない。
- 文字拡大、小画面、VoiceOver、TalkBackの実機確認はPRへ未確認事項として明記する。

## 6. エラーと縮退

- 設定取得や時間表現定義取得を含むsnapshot取得が失敗した場合は、既存と同じ初回エラーまたは期間移動エラーにする。
- fuzzy予定の定義が見つからない、または日内時間へ解決できない場合は、日付ヘッダー下の終日領域へ「ざっくり」として残し、予定自体を消さない。
- 不正な範囲はdomainで`unresolved`にし、UI側で補正規則を増やさない。

## 7. テスト

- domain: 00:00、23:59、瞬間、固定10/15/30/60分、未定、4種類のフェード元情報、日跨ぎ、定義不在。
- presentation: 分数から位置、日跨ぎの分割、4種類のopacity stop、中央一点ピーク、重複レーン、表示ラベル、縮尺計算(実機ピクセルへの丸めを含む)、現在時刻線のtop位置、opacity stopから濃い区間中心・テキスト配置への変換。
- hook: 定義本体と未定分数の取得、予備列と前日を含む取得範囲、予備列を含めた`twoDayStrip`、月範囲を広げないこと、再取得、現在時刻インジケーターの初期値と一定間隔での更新。
- components: 共通時間軸、横2列、絶対位置、4種類のgradient props、終日・空状態、追加操作、読み上げ、縮尺反映、現在時刻線・ラベルの表示条件、予定テキストの配置、枠線なし、セーフエリア余白、24:00ラベルのはみ出し防止、罫線の太さと間隔の均一性。
- 全体: typecheck、lint、format check、全テスト、iOS・Android export。

## 8. 対象外

- 時間表現、フェード比率、未定時間を変更する設定UI。
- 週・月ビュー上のグラデーション。
- ドラッグによる予定時刻変更。
- 表示時間帯や1時間あたりの高さを変更する設定。
- 端末カレンダー同期。
